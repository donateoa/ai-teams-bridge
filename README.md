# ai-teams-bridge

A local CLI that connects a web chat (the "AI Teams" frontend, backed by Firebase) to [Claude Code](https://docs.claude.com/claude-code) running on your machine. Type `/claude <prompt>` in the web chat and the response is generated by your local Claude Code session.

The bridge runs in foreground on your laptop, listens to a Firestore queue for incoming commands, executes them through the Anthropic Claude Agent SDK, and writes the responses back to Firestore so the web chat can render them.

> **Status:** experimental. macOS-first (uses Keychain via `keytar` for credential storage). Linux/Windows support is not implemented yet.

## Requirements

- Node.js >= 20
- macOS
- A Firebase project hosting the AI Teams web chat (you need API key, auth domain, project id, app id)
- A Google OAuth client of type **Desktop app** (Google Cloud Console → APIs & Services → Credentials → Create Credentials → OAuth client ID)

## Install

From npm:

```bash
npm install -g @donateoa/ai-teams-bridge
```

Or build from source:

```bash
git clone https://github.com/donateoa/ai-teams-bridge.git
cd ai-teams-bridge
npm install
npm run build
npm link
```

Both methods expose the `ai-teams-bridge` command in your `PATH`.

## Configure

The bridge loads a `.env` file from the current working directory at startup. Copy the template and fill in the values:

```bash
cp node_modules/@donateoa/ai-teams-bridge/.env.example .env
chmod 600 .env
$EDITOR .env
```

(If you cloned from source, the template is at the repo root.)

Required keys:

- `AI_TEAMS_FIREBASE_*` — from your Firebase project settings
- `AI_TEAMS_GOOGLE_CLIENT_ID` / `AI_TEAMS_GOOGLE_CLIENT_SECRET` — from your OAuth Desktop app

Optional:

- `AI_TEAMS_PERMISSION_MODE` — Claude Code permission mode: `plan` | `acceptEdits` | `default`

Shell environment variables take precedence over `.env`, which is useful for quick overrides.

## Run

```bash
# First-time login (opens the browser for Google OAuth)
ai-teams-bridge login

# Quick configuration check
ai-teams-bridge status

# Start the foreground listener
ai-teams-bridge start
```

Once `start` is running, open the AI Teams web chat and send `/claude <prompt>`. The response will be streamed back from your local Claude Code installation.

## Commands

| Command                | Purpose                                                                  |
| ---------------------- | ------------------------------------------------------------------------ |
| `login`                | Authenticate as your AI Teams user via Google OAuth                      |
| `logout`               | Remove the stored login token from Keychain                              |
| `status`               | Show bridge state: configuration, login, active sessions                 |
| `start`                | Start the bridge: listen for `/claude` commands from your chats          |
| `sessions`             | List active Claude sessions (one per chat)                               |
| `send <chatId> <text>` | Send a text message into a chat                                          |
| `open <chatId>`        | Open an interactive Claude session in the terminal (resume)              |

## Security notes

- OAuth tokens are stored in macOS Keychain via `keytar`, never on disk.
- `.env` is gitignored. Set `chmod 600 .env` to limit reads to your user.
- The bridge runs only while you actively keep `start` in foreground — no background daemon is installed.
